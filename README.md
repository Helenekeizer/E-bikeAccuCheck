# E-bike AccuCheck — gratis statische MVP

Dit is een zelfstandige HTML/CSS/JavaScript-versie van de E-bike AccuCheck, geïnspireerd op de aangeleverde screenshot en de beschreven functionaliteit.

## Routes
- index.html
- accucheck.html
- resultaat.html
- volledig-rapport.html
- confirmation.html

## Belangrijk
De berekening en betaling zijn demo-functionaliteit. Voor echte betalingen, accounts, e-mail en PDF-rapporten is een backend/payment provider nodig.

## Gratis publiceren
Deze statische bestanden kunnen o.a. op GitHub Pages, Cloudflare Pages of Netlify worden gehost.
